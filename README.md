# 2D 横版动作游戏 Demo

一个 Unity 做的 2D 横版动作游戏，有点类恶魔城的味道。是我跟着一套 Udemy 上的 Unity 2D 课程边学边做的，整个状态机和技能系统都是自己跟着敲、跟着调通的，这里把代码整理出来做个记录。

引擎版本：Unity 2022.3.33f1

## 内容：

玩家这边能做的事：

- 左右移动、奔跑、跳跃
- 贴墙下滑、蹬墙跳
- 闪避（Shift），闪避的时候会留个分身
- 鼠标左键三连击普攻，每一段动作和位移都不一样
- Q 键弹反，在敌人出手的那个瞬间按，可以把敌人打晕
- 鼠标右键扔飞剑，按住能看到抛物线，松开扔出去，再按一下召回
  - 飞剑还做了几种形态：普通、在敌人之间来回弹、穿透、原地旋转
- R 键黑洞大招，把敌人定住，按头顶的随机按键标记，然后召唤分身去打
- F 键放水晶，可以跟水晶互换位置（相当于传送）

敌人目前做了骷髅一种：

- 会在平台上来回巡逻，走到边缘或者撞墙会自己掉头，不会掉下去
- 看到玩家会追过来，进入攻击距离就出手
- 被弹反成功会进入眩晕状态，站着闪红灯

| A / D      | 左右移动                                     |

## 代码结构

脚本都在 `Assets/Scirpts` 下面（这个文件夹名是当初建项目时拼错的，一直没改）。

- `Entity.cs`：玩家和敌人的基类，移动、翻转、射线检测、受击击退这些公共逻辑都在这
- `Player/`：玩家相关，主要是一堆状态类
- `Enemy/`：敌人相关，骷髅的状态机在 `Enemy/Skeleton/` 里
- `Skill/`：技能系统，`SkillManager` 统一管理，`Skill_Controllers/` 里是飞剑、黑洞、分身、水晶这些生成出来的物体的控制脚本
- `EntityFX.cs`：受击闪白、眩晕闪红这些特效
- `ParallaxBackground.cs`：背景视差滚动

## 核心思路

整个项目最主要的东西是**状态机**。不管玩家还是敌人，每一种行为（待机、移动、攻击、闪避……）都是一个单独的状态类，每个状态只管三件事：

- 进入的时候干嘛（`Enter`）
- 每一帧干嘛（`Update`）
- 切走的时候干嘛（`Exit`）

状态之间满足条件就互相切换，由一个 StateMachine 来管当前是哪个状态。这样比把所有逻辑堆在一个 `Update` 里写一堆 if-else 清楚很多，后面要加新动作，直接新建一个状态类就行。

攻击判定不是每帧去检测的，而是挂在动画的特定帧上（动画事件），等剑挥到人的那一帧才判定一次，这样伤害和画面能对上。

## 怎么运行

用 Unity 2022.3 打开项目，进入主场景点播放就行。如果只是想看看代码，直接看 `Assets/Scirpts` 里的脚本即可。
